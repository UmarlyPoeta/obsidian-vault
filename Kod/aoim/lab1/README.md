# AOiM Lab 1 — rozwiązanie wzorcowe

Kompilacja i uruchomienie (Java 11+):

```bash
javac --release 11 -encoding UTF-8 -d out src/lab1/*.java
java -cp out lab1.Main
```

W IntelliJ: otwórz katalog `lab1`, oznacz `src` jako Sources Root i uruchom `lab1.Main`.
Opis i teoria: notatka „AOiM Lab 1 — funkcje (klasa abstrakcyjna i interfejs)” w vaulcie.
